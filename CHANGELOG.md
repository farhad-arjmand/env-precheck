# Changelog

## 1.0.0 — 2026-09-27

- Validate required and optional variables using an annotated `.env.example`.
- Check strings, numbers, integers, ports, booleans, URLs, enum choices and JSON.
- Support numeric bounds, minimum string lengths and URL protocol allowlists.
- Apply ordered file overlays and explicit process environment overrides.
- Detect malformed inputs, duplicate keys, invalid rules and empty contracts.
- Emit text or JSON reports without configuration values, with CI exit codes.
- Provide a dependency-free CLI, ESM/CommonJS API and TypeScript declarations.
